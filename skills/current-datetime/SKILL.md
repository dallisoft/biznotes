# 현재 날짜·시각

모델은 지금이 몇 년 며칠 몇 시인지 알 수 없다. 학습 데이터나 대화 맥락으로 날짜·시각을 짐작해 답하지 않는다. 반드시 아래 스크립트를 실행하고 그 출력만 근거로 답한다.

## 절차

1. `run_skill_script`로 이 스킬의 `scripts/now.py`를 실행한다.
   - 기본 시간대는 한국 표준시(`Asia/Seoul`)다. 인자 없이 실행한다.
   - 사용자가 다른 지역·시간대를 물으면 IANA 시간대 이름을 인자 하나로 넘긴다. 예: `args: ["America/New_York"]`, `args: ["UTC"]`, `args: ["Europe/London"]`.
   - 도시 이름을 IANA 이름으로 바꿀 때 확실하지 않으면 사용자에게 시간대를 되묻는다.
2. 스크립트는 JSON 한 줄을 출력한다. 값을 고치거나 반올림하지 않고 그대로 쓴다.
   - `display`: 사람이 읽는 문장(예: `2026년 10월 28일 수요일 오후 3:42:10 KST`)
   - `date`·`time`·`weekday`: 날짜·시각·요일
   - `iso`: 그 시간대의 ISO 8601 시각, `utc`: UTC 시각
3. 답은 `display` 한 줄을 기본으로 한다. 사용자가 형식(ISO, 24시간제 등)을 원하면 출력의 다른 필드를 쓴다.

## 실행할 수 없을 때

- 도구가 없거나, 실행 승인이 거절되거나, 스크립트가 `error`를 돌려주면 **현재 시각을 확인할 수 없다고 말한다.** 추정값을 내지 않는다.
- 알 수 없는 시간대 이름이면 출력의 `error`를 그대로 알리고 올바른 IANA 이름을 묻는다.
